# Math Care Center — Modern Educational Platform

**Math Care Center** is a comprehensive mathematics educational platform and documentation portal built with Next.js 16 (App Router), React 19, Tailwind CSS v4, KaTeX math rendering, and Supabase / PostgreSQL.

![Math Care Center](public/logo.svg)

---

## ✨ Features

- 📚 **Start Guide & Roadmap**: Clear prerequisite sequence and high-density **Formula Cheat Sheet**.
- 🎓 **Structured Courses**: Calculus, Linear Algebra, Modern Algebra, and Probability with 1-click free enrolment.
- ✍️ **Blog & Deep Dives**: Mathematics essays on geometric intuition, AI linear algebra, and research strategies.
- 🎥 **Embedded Video Lectures**: Integrated YouTube video players for every course module.
- 🧮 **KaTeX Math Rendering**: Full LaTeX support for inline `$x^2$` and block `$$...$$` equations.
- ⚡ **Supabase & PostgreSQL**: Native Supabase authentication and database integration with cookie fallback.
- 🔍 **Search & Filters**: Real-time course and document search with tag filters (`⌘K`).
- 👤 **Student Dashboard**: Completed lesson history, bookmarking, and progress tracking.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16+ (App Router) & React 19
- **Styling**: Tailwind CSS v4 & PostCSS
- **Math Engine**: KaTeX
- **Database & Auth**: PostgreSQL via Drizzle ORM & Supabase
- **Icons**: Lucide React
- **Dev Tools**: Docker, DevContainer, TypeScript strict mode
